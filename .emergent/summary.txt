<product_requirements>
The user requested a modern, responsive, and user-friendly web-based order management system. Key features include:
- **Order Entry Screen**: Form for personal (Name, Phone, optional TC No, Email, international checkbox with country dropdown for Europe), shipping (Province/City dropdowns for 81 Turkish provinces and all districts, Address, Cargo Company: DHL as default from options including Yurtiçi, Aras, Sürat, PTT), product (LED Lamba, Mug, Magic Mug, Keychain, Personalization textarea, Color dropdown: Günışığı default, Altlık Seçimi dropdown: Dikdörtgen/Kalp - active only for LED Lamba, Altlık Yazısı textarea), and payment (Payment Type dropdown: Kapıda Ödeme, Havale, Web, Web Kapıda Ödeme; Amount; Gift Package checkbox; Order Note textarea). All fields are saved to the database.
- **Order Listing Screen**: Table displaying Order No, Date, Name, Phone, Province, Payment Type, Amount, Status (dropdown: Yeni Sipariş, Hazırlanıyor, Üretime Verildi, Üretim Bitti, Eksik Bilgi, Teslim Edildi), Cargo Company, and action buttons (Print, Edit, Delete). Status automatically changes to Üretime Verildi upon printing.
- **Printing Feature**: 10x10 cm label printout (PDF/printer) with Order No, Name, Product Type, Color, Personalization Text, Cargo Company, Address (abbreviated single line), Payment Type & Amount, Altlık Seçimi, Altlık Yazısı, Gift Package icon. A separate 8x5 cm horizontal print for Order Notes with a specified PNG background.
- **Additional Features**: Filter/search (date, province/city, payment type, search bar for name/phone/order no), status color coding (New = blue, Production = orange, Completed = green), data persistence (DB).
- **Design & UX**: Modern, professional, mobile-friendly, compact layout, side-by-side Name/Surname, new order button to show/hide form, gift package/2nd product icons, no time in date, no '#' in order number.
- **User Management**: Login with username/password (admin/admin default), settings section with user management (add, remove, edit users), role-based permissions, and configurable table column visibility per user.
</product_requirements>
